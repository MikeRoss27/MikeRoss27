## 02 — Current Focus

**Volt** — An open-source, keyboard-first launcher for Windows, macOS, and Linux. Search applications and files, run commands, manage clipboard history, calculate, convert units, and extend through TypeScript plugins.

**BaseMyAI** — Private memory infrastructure for AI agents. A local-first, encrypted, temporal memory engine providing durable persistence, agent isolation, local retrieval, and multiple interfaces through Rust, CLI, MCP, REST, and Python.

## 03 — Selected Work

### Volt
**Everything on your computer. One shortcut.**

An open-source, keyboard-first launcher for Windows, macOS, and Linux. Search applications and files, run commands, manage clipboard history, calculate, convert units, and extend through TypeScript plugins.

`Tauri 2` `Rust` `React` `TypeScript` `SQLCipher`

[Website](https://voltlaunchr.com) · [Source](https://github.com/VoltLaunchr/Volt)

---

### BaseMyAI
**Private memory infrastructure for AI agents.**

A local-first, encrypted, temporal memory engine built in Rust. Provides durable persistence, agent isolation, local retrieval, and multiple interfaces through Rust, CLI, MCP, REST, and Python.

`Rust` `Tokio` `axum` `candle` `MCP`

[Website](https://basemyai.com) · [Source](https://github.com/BaseMyAI/basemyai)
