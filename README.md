## About

I'm **Nathan**, a self-taught developer based in France. I design and build software end to end: product interfaces, native integrations, backend services, storage engines, deployment and release tooling.

My work sits at the intersection of **systems programming, local-first software, applied AI and security research**. I like polished interfaces backed by understandable architecture, and tools that solve real problems rather than just look impressive in a demo.

> Small interfaces. Serious engineering. Software people can own.

## How I build

| Principle | In practice |
| :--- | :--- |
| **Local ownership** | Prefer offline-capable systems, portable data and explicit boundaries around network access. |
| **Engineering clarity** | Design interfaces and architecture together; keep failure modes, permissions and trade-offs visible. |
| **Evidence over hype** | In security and AI, favor reproducible tests and transparent limitations over ambitious claims. |
| **End-to-end thinking** | Care about the complete path from the first interaction to packaging, observability and updates. |
